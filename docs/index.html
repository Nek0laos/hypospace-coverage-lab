DECODING METHOD

Remember the prefix.

After sampling a structure, the decoder records how often each height followed each partial sequence. When the same prefix returns, it lowers the scores of frequently chosen heights. The adjustment grows with the spread of the model’s token scores.

Every occupied cell is a vertical stack of one to three cubes. This shared output constraint guarantees validity for all five controls. Recovery measures the fraction of distinct legal structures found.
